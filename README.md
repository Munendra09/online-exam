# Exam Portal Pro Frontend
Next.js App Router + Tailwind CSS frontend.

## Setup
```bash
cp .env.example .env.local
npm install
npm run dev
```
Pages:
- `/login`, `/register`
- `/dashboard`, `/exam`, `/exam/[id]`, `/result`, `/result/[id]`
- `/admin`, `/admin/students`, `/admin/exams`, `/admin/questions`
